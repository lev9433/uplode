# CodeKlar

Eine responsive deutschsprachige Lernseite für die Grundlagen von Python, Java und Rust.

## Lokal starten

Öffne `index.html` in einem aktuellen Browser. Es werden keine zusätzlichen Pakete oder Build-Schritte benötigt.

Die Lektionen und Quizfragen funktionieren direkt im Browser. Der persönliche Fortschritt wird lokal im Browser gespeichert.
